Put Sports Master on your phone Home Screen

This makes Sports Master feel like an app. It still runs as the website, but it opens from your phone’s Home Screen with the trophy icon instead of making everyone hunt through browser tabs like a lost raccoon.

iPhone or iPad

  1. Open Sports Master in Safari. This bit matters. iPhones are fussy little monarchs about Home Screen web apps.
  2. Tap the Share button. It usually looks like a square with an arrow escaping from it.
  3. Scroll through the options and tap Add to Home Screen.
  4. Leave the name as Sports Master, unless you want to call it something suspicious like “Definitely Work”.
  5. Tap Add. The trophy icon should appear on your Home Screen, ready for weekly glory.

Android phone or tablet

  1. Open Sports Master in Chrome, or your usual Android browser if it supports Home Screen shortcuts.
  2. Tap the three-dot menu. The tiny kebab of destiny.
  3. Tap Add to Home screen, Install app, or similar wording depending on the browser.
  4. Confirm the name as Sports Master.
  5. Tap Add or Install. You now have a trophy-powered launch button.
Small print, but not boring: this is a Progressive Web App (PWA), which means it is still your website, just dressed up nicely for the phone Home Screen. No App Store. No Google Play. No forms in triplicate.

How Sports Master works

Sports Master is the weekly office sports challenge where everyone gets to be a commentator, bookmaker, statistician, and overconfident pundit all at once.

1. Register and wait for approval

  1. Register with your full name, preferred name or nickname, email address, and password.
  2. New players start as pending approval. This stops randoms, robots, cousins, and suspiciously well-informed houseplants from joining the game.
  3. An admin approves new players. Once approved, you can enter events, submit predictions, and play Stop the Timer.

2. Create your event

  1. Each active player may create one event column per week.
  2. The event must happen during the event window: Friday 1700 to Monday 0800 New Zealand Time.
  3. Add the sport, event name, event link, start time, challenge description, and prediction format.
  4. Keep the prediction format clear. “Winner’s name” is good. “Vibes” is funny, but the scoring committee will cry.

3. Enter predictions

  1. Everyone submits predictions before the weekly lock.
  2. Predictions stay hidden until the reveal, so nobody can copy the office oracle.
  3. If an event has no tie-breaker, duplicate predictions are blocked.
  4. If an event has a tie-breaker, shared main predictions are allowed, but the written tie-break answer decides the awkward stuff.
  5. Stop the Timer is no longer available as an event tie-break option. It is reserved for the overall weekly winner tie-breaker, where it belongs, glowing ominously in the corner.

4. Results and winners

  1. After the Friday deadline, event owners can enter the actual result and select the winning prediction.
  2. Admins can help manage results and winners if someone is away, unavailable, or trapped in a meeting called “quick sync”.
  3. The winner of each event gets one point. Everyone else gets character development.
  4. The leaderboard shows the selected week and total points across saved weeks.
Late event warnings: the game shows when an event was first saved and last changed. Friday entries can be flagged as late or very late, because “here is my event with twelve minutes left” is technically legal but socially spicy.

Stop the Timer instructions

Stop the Timer is the overall weekly tie-breaker. It is fast, unfairly tense, and has a big red button, which automatically makes it 37% more official. Practice mode is also available if you want to train your thumb without troubling the leaderboard.

  1. From the main Sports Master page, press STOP THE TIMER.
  2. The Stop the Timer page opens separately. This keeps the main game tidy and gives the tie-breaker its own dramatic little stage.
  3. The official mode gives you one saved attempt for the selected week. Practice mode gives you unlimited attempts for laughs, training, and absolutely no official glory.
  4. Press Start the timer. Your personal challenge appears. It may be Classic Stop, Countdown Stop, or Bounce Stop.
  5. The running timer is hidden. This is where confidence leaves the building.
  6. Classic Stop: the hidden timer counts up from zero. Stop as close as possible to the target elapsed time.
  7. Countdown Stop: the hidden timer counts down from 10 seconds. Stop when you think the remaining time has reached your target.
  8. Bounce Stop: the hidden value starts at the low end, reaches the high end 2 seconds later, then returns to the low end every 4 seconds. The end indicators flash when it bounces. There is no moving line, because that would be far too kind.
  9. Press the big red Stop the Timer button when you think your target time has passed.
  10. Your result is saved, including your target, result, difference, and audit flags.
  11. After saving, the page performs its mission-complete self-destruct sequence. If your browser refuses to close the tab, use the return button. Some browsers are cowards.

Fair play and audit flags

This is still a free static website, so it cannot be Fort Knox. But it does make casual cheating harder and more visible.

What gets checkedWhy it matters
Server timestampsFirestore records start and stop timestamps so there is a basic timing trail.
Client timing mismatchIf the browser-reported timing and server timing look odd, the attempt can be flagged for review.
Page focus and visibilityIf the page was hidden or lost focus during the attempt, it can be marked suspicious.
Perfect or very strange resultsIf someone lands exactly on the target or records a bizarre result, the audit column can politely raise an eyebrow.
Translation: play nicely. If you try to defeat the office sports game with developer tools, you may win the point but lose the moral high ground, which is worth at least two points in the pub.

Troubleshooting

The icon did not update

Favicons are aggressively cached. Browsers hoard them like tiny digital dragons. Try a hard refresh, close and reopen the browser, or wait a little while.

I cannot play after registering

That is probably correct. New players need admin approval before they can enter events, predictions, or Stop the Timer.

Stop the Timer will not close itself

Some browsers block automatic tab closing unless the page was opened in a certain way. Use the return button and imagine the explosion happening off-screen.

The page looks old

Hard refresh with Ctrl + F5 on Windows. On a phone, close the browser tab and reopen Sports Master from the Home Screen or browser.
